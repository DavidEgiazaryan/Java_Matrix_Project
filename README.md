# Матрицы комплексных чисел

Учебный проект на Java для работы с матрицами комплексных чисел.

## Возможности

- Сложение и умножение матриц.
- Деление через обратную матрицу.
- Транспонирование.
- Вычисление определителя.
- Сохранение результата для дальнейших операций.

## Файлы

- Complex_number.java — комплексное число и операции с ним.
- ComplexMatrix.java — матрица и операции над матрицами.
- Main.java — ввод данных и консольное меню.

## Запуск

Открыть проект в IntelliJ IDEA и запустить Main.java.
Ввести размеры и элементы двух матриц, затем выбрать операцию в меню.

Для каждого комплексного числа действительная и мнимая части вводятся отдельно.
Пункт 11 позволяет использовать результат как матрицу A.
